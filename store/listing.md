## 자세한 설명 (4,000자)

```
🪜 누가 걸릴까? 사다리로 정해요

「사다리타기」는 참가자와 결과를 적고 사다리를 타면 끝나는 가장 간단한 뽑기 앱입니다.
커피 사기, 설거지 당번, 발표 순서, 회식 벌칙… 애매한 결정은 사다리에 맡기세요.

✨ 주요 기능

• 2~10명
  인원을 +/- 로 정하고 이름을 적으세요. 이름은 다음에도 기억해 둡니다.

• 결과 프리셋
  - 당첨 1개: 한 명만 당첨, 나머지는 꽝
  - 꽝 1개: 한 명만 꽝
  - 순위: 1등 ~ N등
  - 직접 입력: 벌칙·역할·메뉴, 무엇이든

• 사다리 타는 애니메이션
  위쪽 이름을 누르면 색깔 선이 사다리를 타고 내려가 결과에 도착합니다.
  속도는 설정에서 느리게·보통·빠르게.

• 결과는 가려두기
  사다리 아래 결과는 도착하기 전까지 ? 로 가려집니다. 눈 모양 버튼으로 미리 볼 수도 있어요.

• 모두 타기
  버튼 한 번으로 전원이 차례대로 사다리를 탑니다.

• 다시 섞기
  가로줄을 무작위로 새로 만듭니다. 이웃한 줄마다 가로줄이 최소 하나씩 있어 결과가 한쪽으로 쏠리지 않아요.

• 결과 정리 · 복사
  이름 → 결과를 한 번에 보고, 텍스트로 복사해 단톡방에 바로 붙여넣으세요.

🔒 개인정보 걱정 없이

회원가입도 로그인도 없습니다. 입력한 이름과 결과는 휴대폰 안에만 저장됩니다.
인터넷 외에 어떤 권한도 요구하지 않습니다.

🎨 깔끔한 디자인

다크 모드를 지원하는 청록색 테마. 한국어 · 영어 · 일본어 · 중국어(간체)를 지원합니다.

---
※ 앱은 광고를 포함하고 있습니다 (하단 배너, 전면 광고는 하루 1회).
```
